# Memory Policy

Before storing new workflow memory, read `memory-index.md` and run a memory value check.

Store memory only when it affects future work, prevents repeated mistakes, records a durable choice, tracks concrete future work, or helps teammates safely run/change this repository.

Do not store raw session notes, duplicated rules, obvious facts, noisy tool output, local-only paths, secrets, or customer data.

## Memory Locations

- Index: `docs/workflow/memory-index.md`
- Templates: `docs/workflow/templates/` (starting point for each memory type)
- Decisions: `docs/decisions/`
- Plans: `docs/workflow/plans/`
- Specs: `docs/workflow/specs/`
- Tasks: `docs/workflow/tasks/`
- Ideas: `docs/workflow/ideas/`
- Learnings: `docs/workflow/learnings/`

Protected files: `CLAUDE.md` and `AGENTS.md`. Propose changes before editing them.

## Token Rules

Update the index whenever detail memory changes. Open archived/completed memory only when the task specifically needs historical context.
