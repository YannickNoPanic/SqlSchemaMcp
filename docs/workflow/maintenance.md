# Maintenance

Run or propose a memory sweep when active plans/tasks are stale, docs grow materially, repeated rules appear, workflow memory conflicts with current repository behavior, or archived history becomes default context.

## Checklist

- [ ] `memory-index.md` is current and compact.
- [ ] Active plans are actually active.
- [ ] Completed plans are moved, summarized, or archived.
- [ ] Tasks are current, actionable, or archived.
- [ ] Ideas are validated, promoted, or archived.
- [ ] Learnings are still useful or merged into durable docs.
- [ ] Protected rules are not duplicated across multiple files.
- [ ] Large workflow docs are summarized.
- [ ] Archive/completed folders are not loaded by default.
