# Plugins and Skills

Use recommended tools when available. If unavailable, follow the documented workflow manually and state the fallback.

Recommended workflow skills:
- `use-memory`: classify memory/workflow tasks.
- `repo-bootstrap`: apply repository workflow baseline.
- `memory-capture`: capture decisions, learnings, plans, and specs.
- `memory-sweep`: prune stale workflow memory.
- `workflow-review`: score workflow health.

Superpowers-generated files under `docs/superpowers` are tool output. Canonical team workflow lives under `docs/workflow`.
