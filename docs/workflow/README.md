# Workflow

This folder contains team workflow memory for this repository.

Start with `memory-index.md`. Open detail files only when the index shows they are relevant to the current task.

## Files

- `memory-index.md`: compact entrypoint for active memory.
- `memory-policy.md`: what to store and what not to store.
- `plugins.md`: recommended tools and fallbacks.
- `maintenance.md`: memory sweep triggers and checklist.
- `templates/`: copy-paste starting points for each memory type (decision, task, idea, learning, plan, spec). Use these instead of inventing a new format.
- `plans/`: active, completed, and archived implementation plans.
- `specs/`: active, completed, and archived design specs.
- `tasks/`: future work that should not be forgotten.
- `ideas/`: possible directions that need validation.
- `learnings/`: workflow learnings that may later become rules.

Archived and completed files are not default context.
